# Source package manifest

This archive includes the complete editable Songa AI 2.0 source project:

- `src/` — React/TypeScript application, all screens, styles, provider adapters and client utilities.
- `public/` — logos, favicon and static browser-safe assets.
- `supabase/functions/` — existing flight, WhatsApp, AI, map, PayPal and shared commerce Edge Functions.
- `supabase/migrations/` — existing migration history plus Songa 2.0 payment, commerce, webhook reliability and traveller personalisation migrations.
- `scripts/` — optional static ESM fallback builder.
- Vite, TypeScript, Tailwind, ESLint, Vercel and Supabase configuration.
- `package.json` and `package-lock.json` for reproducible dependency installation.
- `.env.example` containing browser-safe placeholders and comments for server-only secrets.
- MIT licence and detailed PowerShell, Supabase, accommodation-provider, product and release documentation.

Deliberately excluded:

- `node_modules/` — install the locked dependencies with `npm.cmd ci`.
- `.env`, `.env.local` and all real secrets.
- `dist/` — generated by the standard `npm.cmd run build`; no stale fallback output is packaged.
- `.git/`, `.vercel/`, local editor state and caches.
